# ============================
# 5. Preparar Interação com o LLM
# ============================

- Carregar Small_LLM_Model do llm_sdk.
- Usar encode() para converter texto em tokens.
- Usar get_logits_from_input_ids() para obter logits.
- Carregar vocabulary.json com get_path_to_vocabulary_json().
  Explicação: vais precisar disto para fazer constrained decoding.


# ============================
# 6. Implementar Constrained Decoding
# ============================

- Criar loop de geração token a token.
- Em cada passo:
    - Identificar tokens válidos para manter JSON correto.
    - Bloquear tokens inválidos (logits = -inf).
- Garantir:
    - JSON sempre válido.
    - Estrutura fixa: {"name": ..., "parameters": {...}}
    - Tipos corretos (string, number, boolean).
  Explicação: é a parte mais importante do projeto; o PDF diz que não podes confiar no modelo.


# ============================
# 7. Escolher a Função Correta
# ============================

- Passar o prompt ao modelo.
- Usar o modelo para decidir qual função chamar.
- Extrair argumentos usando o LLM + constrained decoding.
  Explicação: não podes usar heurísticas; a escolha deve vir do modelo.

- Validar:

    - Sem chaves extra
    - Tipos corretos
  Explicação: o avaliador vai abrir este ficheiro e verificar tudo.
